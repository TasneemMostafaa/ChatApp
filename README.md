# ChatApp

A real-time Flutter chat app using Firebase Authentication and Cloud Firestore.

## Features

1. User registration and login with Firebase Authentication.
2. Real-time message updates using Cloud Firestore.
3. Message sending and recieving.
4. Custom chat bubbles for messages.
5. State management using Cubit.
